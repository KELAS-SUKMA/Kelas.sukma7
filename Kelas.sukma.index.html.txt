- Video Pembelajaran: list video, admin tambah link YouTube + judul
- Kalkulator SKD: input skor TWK TIU TKP -> prediksi lolos + passing grade

=== KELAYAKAN & ANTI ERROR ===
- Semua localStorage pakai try-catch, fallback default value jika parse error
- Semua render pakai optional chaining (data?.programs || {})
- Semua gambar pakai base64 atau placeholder picsum.photos, jangan URL eksternal yang bisa 404
- Semua state ada initial value tidak undefined
- Toast notifikasi sukses/gagal tiap aksi pakai alert atau custom toast
- Responsive mobile: modal jadi bottom sheet, grid jadi 1 kolom
